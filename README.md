## 三档线路的差别，就在「回程走哪张网」

LightLayer 把路由分成 Premium、Standard、Global 三档，只有 Premium 是 CN2 GIA。这个划分比很多商家含糊的「回国优化」标签清楚，也正因如此容易看错：Standard 听起来像标准优化，实际走的是普通直连回程。

官方对 Premium 的描述是：中国电信走 CN2，中国联通和中国移动走 CMIN2。实际回程路径建议自己 traceroute 一遍确认，商家的文字描述和线路实况偶尔会有出入。

要看懂这条描述，得先知道几个词：

**CN2 GIA** 是中国电信的高端承载网（AS4809），去程回程都做优化，晚高峰丢包和延迟表现比普通线路稳，带宽成本也高。**CN2 GT** 是中端线路，去程优化，回程不一定走 CN2，晚高峰体验会差一截。行业里说的「回国优化」是 CN2 GIA、CN2、AS9929、CMIN2 这一类线路的统称，看到这个词不能直接等同于 GIA。

判断一台机器是不是真 GIA，看三件事：商家有没有写明回程走哪条线、有没有公开测试 IP、能不能在晚高峰跑一次 traceroute。页面没给测试 IP 的，下单前发工单要一个，比事后猜省事。

Premium 和 Standard 的年付差是 $10，跟 Global 差 $20。如果大陆访问是你的主要场景，这 $10 花得值；如果只是跑海外业务或者拿来做备份节点，Global 就够。
